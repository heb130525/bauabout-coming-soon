BAUABOUT 준비중 페이지

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 index.html을 저장소 최상단에 업로드합니다.
3. 저장소의 Settings → Pages로 이동합니다.
4. Build and deployment의 Source를 "Deploy from a branch"로 선택합니다.
5. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
6. GitHub에서 생성된 주소로 페이지가 정상 표시되는지 확인합니다.

그다음 bauabout.co.kr 연결을 진행하면 됩니다. 네이버웍스 메일에 사용하는
MX/TXT 레코드는 삭제하거나 변경하지 마세요.
